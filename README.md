# 🌐 Melek Abdelmaksoud — Portfolio

A modern, bilingual (FR/EN) personal portfolio showcasing my journey in **Web Development & Multimedia**.

🔗 **Live Site:** [portfolio.melekabdelmaksoud72.workers.dev](https://portfolio.melekabdelmaksoud72.workers.dev/)

---

## ✨ Features

- **Bilingual** — Seamless French / English switching with persistent language preference
- **Responsive** — Fully adapted for mobile, tablet, and desktop
- **Modern Design** — Clean layout with smooth gradients and thoughtful typography
- **Accessible** — Semantic HTML, ARIA attributes, and keyboard-friendly navigation

## 🛠️ Built With

- HTML5 / CSS3
- Vanilla JavaScript
- [Google Fonts](https://fonts.google.com/) — DM Sans & Space Grotesk

## 📂 Structure

```
├── index.html      # Main page
├── style.css       # Styles
├── script.js       # Language toggle & menu logic
├── og-image.png    # Social media preview image
└── README.md       # This file
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/malekabdelmaksoud/Portfolio.git
   ```
2. Open `index.html` in your browser — no build step needed!
