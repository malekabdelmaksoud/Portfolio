PORTFOLIO BILINGUE – MELEK ABDELMAKSOU D

Le site propose deux langues : français (FR) et anglais (EN).
Le sélecteur FR / EN se trouve dans le menu en haut de la page.
La langue choisie est mémorisée dans le navigateur.

Pour tester :
1. Décompressez le fichier ZIP.
2. Ouvrez index.html dans un navigateur.
3. Cliquez sur FR ou EN pour changer instantanément la langue.

Pour publier gratuitement sur GitHub Pages :
1. Créez un dépôt GitHub nommé portfolio.
2. Ajoutez index.html, style.css et script.js.
3. Dans Settings > Pages, choisissez Deploy from a branch, puis main / root.
4. Ouvrez l'adresse publique générée par GitHub Pages.

Avant publication, vérifiez les informations des stages, projets et coordonnées.
